# O Fant A Girrr

Pagina della lega di fantacalcio: rosa, probabili formazioni, percentuali di scambio, svincolati e infortunati.

- `index.html` è la pagina.
- `data.json` contiene i dati e viene aggiornato in automatico il martedì e il venerdì.

Il sito è pubblicato con GitHub Pages dal ramo `gh-pages`.
